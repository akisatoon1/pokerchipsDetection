# Web アプリの層

Web アプリ (`web/`) のコードの層の分け方をまとめる.
言語によらない規則 (規則と入出力を分ける, 入口で検証するなど) は [../code-rules.md](../code-rules.md) にあり,
ここではそれを Web アプリでどう当てはめるかを決める. どのディレクトリがどの層かは [typescript.md](typescript.md) にある.

## 層と依存の向き

コードを次の層に分け, 依存は矢印の向きにだけ持つ. 逆向き (規則が API を知るなど) の依存は作らない.

```
画面 ──HTTP──→ API ──→ 規則
                └────→ DB アクセス
```

| 層 | 役割 | してはいけないこと |
|---|---|---|
| 画面 | 入力を受けて API を呼び, 結果を表示する | 点数の計算などの規則を持つ. 規則は API の結果を使う |
| API | 入力を検証し, 規則と DB アクセスを呼び, 応答の形に変える | 規則の中身を書く. SQL を直接書く |
| 規則 | 計算と判定 | DB・HTTP・画面に触れる |
| DB アクセス | データの読み書き. SQL はここにだけ書く | 規則の判定をする |

## 入力の検証

外から来る入力 (HTTP の本文など) は API の入口で検証する. 規則と DB アクセスは, 検証済みの値だけを受け取る.

## 用語

名前は [app.md](../../web/app.md) と [scoring.md](../../web/scoring.md) の用語に合わせる.
たとえば Match, Player, Round, Entry, 初期点数, 持ち点, 増減, 累計.
