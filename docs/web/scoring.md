# 点数計算

みんなでアプリを使って遊んだときの点数の計算方法をまとめる.
複数のラウンドからなるマッチで, ラウンドごとの点数の増減と, マッチ全体の累計を求める.
アプリを使う人と使わない人が混ざっていてもよい.
この計算を行うアプリの仕様は [app.md](app.md) にまとめる.

## 用語

| 用語 | 意味 |
|---|---|
| マッチ | その日に遊ぶラウンドをまとめたもの. マッチを作り, その中にラウンドを追加していく. |
| ラウンド | 1 回のゲーム. マッチの中で何回でも行える. |
| 初期点数 S | 各ラウンドの開始時に全員が持つ点数. 全員同じ値. |
| 持ち点 pᵢ | ラウンドの終了時にプレイヤー i が持っている点数. |
| 増減 dᵢ | そのラウンドでプレイヤー i が増やした (減らした) 点数. |
| 累計 | マッチの中の確定した全ラウンドの増減の和. |

## 値の範囲

- 初期点数 S は 1 以上の整数とする.
- 持ち点 pᵢ は 0 以上の整数とする. チップの点数は整数なので, 小数は扱わない.

## 計算のルール

1. 各ラウンドは, 全員が初期点数 S から始める. 前のラウンドの持ち点は持ち越さない.
2. ラウンドの終了時に, 各プレイヤーの持ち点 pᵢ を入力する. ラウンドを確定するまでは何度でも直せる.
3. そのラウンドの増減を dᵢ = pᵢ − S とする. 持ち点が S より多ければプラス, 少なければマイナスになる.
4. ラウンドを確定すると, そのラウンドの持ち点は変更できなくなる.
5. マッチで引き継ぐのは増減だけにする. プレイヤー i の累計は, 確定した全ラウンドの dᵢ の和とする.
   確定していないラウンドの増減は累計に含めない.

| | 対象 | 式 |
|---|---|---|
| 増減 | 入力中・確定のラウンドで, 持ち点が入っている人 | dᵢ = pᵢ − S |
| 累計 | 確定したラウンドだけ | Σ dᵢ |
| 検査 | 全員の持ち点がそろったラウンド | Σpᵢ = S × n でなければ警告 |

## 確定前の表示

入力中のラウンドでも, 持ち点が入っている人の増減を計算して表示する.
確定する前に全員が結果を見て, 入力の間違いに気づけるようにするため.
持ち点を入れていない人は「未入力」と表示する.

## 入力の検査

点数はプレイヤーの間でやり取りされるだけで, 増えも減りもしない.
そのため入力に間違いがなければ, 次の式が成り立つ (n はプレイヤーの人数).

- 持ち点の合計: Σpᵢ = S × n
- 増減の合計: Σdᵢ = 0

検査は全員の持ち点がそろってから行う. 成り立たないときは警告を出す.

- 確定前の画面にも警告を出す.
- 警告が出ても確定はできる. そのまま確定するかどうかはリーダーが選ぶ.
- 確定したあとの結果表示にも, 合計が合っていなかったことを示す.

## 例

S = 100 点で, プレイヤーが A, B, C の 3 人の場合.

| | A | B | C | 合計 |
|---|---|---|---|---|
| ラウンド 1 の持ち点 | 150 | 150 | 0 | 300 (= 100 × 3) |
| ラウンド 1 の増減 | +50 | +50 | −100 | 0 |
| ラウンド 2 の持ち点 | 80 | 100 | 120 | 300 (= 100 × 3) |
| ラウンド 2 の増減 | −20 | 0 | +20 | 0 |
| **累計** | **+30** | **+50** | **−80** | 0 |

ラウンド 2 は, ラウンド 1 の持ち点 (150, 150, 0) ではなく, 全員 100 点から始める.
ラウンド 1 の結果は累計にだけ残る.
