## 計画

core が色を間違えたチップ (`unknown` を含む) を, 確認画像のチップ 1 枚ごと (合わせ目と合わせ目の間の帯ごと) に手で直せるようにする.
持ち点は直した色で求める. 直したチップと直していないチップは, 見て区別できるようにする.

### 決めたこと

- **ブランチ**: 人の指示で, main でなくブランチ `feat/web-manual-chip-correction` にコミットする. main への取り込みと push は, 人に言われたときだけ行う.
- 直せるのは色だけにする. 枚数 (合わせ目) と, 数えられなかったスタックは直さない. 指示が色の間違いのため.
- 直した色は写真ごとに持つ. 写真を外したら, その写真の直した色も消える. 保存はしない (検出画面を閉じたら消える).
- 「チップから入力」と「数えるだけの画面」は同じ部品 (`chip-analysis.ts`) を使うので, どちらでも直せる.

### 機能 1: チップの色を手で直す

画面の動き:

- スタックごとの確認画像の下に, 開閉できる「色を直す」を置く. 開くと, 上から順にチップ 1 枚ごとの行が並ぶ.
  行には「n 枚目」, 色の見本, 色を選ぶ欄 (7 色) を出す.
- 確認画像の帯 (チップ 1 枚) を押すと, 「色を直す」が開き, そのチップの行の欄に移る. 帯が細いと押しにくいので, 行の一覧も使えるようにする.
- 色を選ぶと, すぐに確認画像の右の色のラベル, 「色: 赤 ×3, ...」の行, 持ち点を出し直す.
- 区別:
  - 直したチップは, 確認画像のラベルの列で帯の背景を明るい橙にし, 名前の前に「✎」を付ける.
    行は左に橙の線を引き, 「直した (検出: 青)」と出し, 「元に戻す」ボタンを置く.
  - 検出のときの色と同じ色を選び直したら, 直していないものとして扱う.
  - 色が分からなかった (`unknown`) チップで, まだ直していないものは, 行を赤で「色が分かりません」と出す.
  - 「色を直す」の見出しと写真ごとの見出しに, 直したチップの枚数を出す. 閉じても直したことが分かるようにするため.
  - 持ち点の下に, 直した色を含むときは「手で直した色 n 枚を含みます」と出す.
- 求められない理由の文に, 色を直せることを書く (「…の上から 3 枚目の色が分かりません」のあとの案内).

変えるファイル:

- `web/src/rules/color-corrections.ts` (新規): 直した色を持つ型と, 直す・戻す・解析の結果に当てる純粋な関数.
- `web/test/rules-color-corrections.test.ts` (新規): 上のテスト.
- `web/src/client/color-editor.ts` (新規): 「色を直す」の行の一覧.
- `web/src/client/result-views.ts`: 確認画像のラベルの列を, 直した色で描き直せるようにする. 帯を押したときを伝える. 理由の文.
- `web/src/client/pages/chip-analysis.ts`: 写真ごとに直した色を持ち, 直した結果で見出しと持ち点を出し直す.
- `web/src/client/pages/chip-input-dialog.ts`: 「手で直した色 n 枚を含みます」.
- `web/src/client/style.css`: 行の見た目.
- `docs/web/app.md`: 「チップの検出」に「色を手で直す」を足す.
- `docs/worklog.md`: 足したファイル.

テストの観点:

- 直した色は, 解析の結果のそのチップの色だけを変える. ほかのチップ, ほかのスタックは検出のまま.
- 直した結果から求めた持ち点は, 直した色の点数で計算される.
- `unknown` のチップを直すと, 止めずに持ち点を求められる.
- 同じチップを 2 回直したら, あとの色になる.
- 検出のときと同じ色に直したら, 直したものに数えない.
- 戻すと検出のときの色になり, 直したものに数えない.
- 直しても, 元の解析の結果は変わらない.
- 解析の結果にない位置 (スタックやチップの番号が範囲外) を直そうとしたら, 例外にする (画面の作り間違いのため).
- 画面 (人に依頼する): 帯を押すと行に移る. 直したチップと直していないチップが見分けられる. 直すと持ち点が変わり, 「この点数を入れる」でその値が入る.

- 変更:
  - 確認画像の下の「色を直す」の行の一覧を消す. 代わりに, 確認画像の帯 (右の色のラベル, または同じ高さの画像) を押すと,
    その帯の上か下に 7 色のパレットを出し, 押した色にその場で直す. パレットには「上から n 枚目」, 直したチップなら検出のときの色,
    「元に戻す」と「閉じる」を置く. パレットの外を押すか, 色を選ぶと閉じる.
  - 押した帯は白い枠で囲み, どのチップを直しているかを分かるようにする.
  - 色の分からない (`unknown`) チップで, まだ直していないものは, ラベルの列の帯の背景を暗い赤にする. 直すところを画像の上で見つけやすくするため.
  - 拡大はブラウザのピンチのまま (今と同じ). 確認画像は, 画面の画素の細かさでなく, 元の写真の細かさ (上限あり) で描く. 拡大してもぼやけないようにするため.
  - 直したチップの枚数は, 写真ごとの見出しと, 検出画面の持ち点の下に出す (一覧の見出しはなくなる).
  - 変えるファイル: `web/src/client/color-editor.ts` を消し, `web/src/client/color-picker.ts` (新規) にパレットを置く. ほかは計画の表のとおり.
  - テストの観点 (画面, 人に依頼する) を次に替える: 帯を押すとパレットが出て, 色を選ぶとその場でラベルが直る. 拡大したままでも押して直せる. 拡大してもぼやけない.
