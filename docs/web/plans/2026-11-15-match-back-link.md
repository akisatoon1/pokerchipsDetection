# マッチの画面からトップページに戻るリンクを足す

承認日: 2026-11-15

## 人の指示

```
マッチに入ったあと、トップページに戻れない。戻れるようにリンクを追加せよ。
```

```
一番下に書いて。
```

最初に示した計画ではリンクをマッチ名の見出しの上に置くとしていたが, 2 つ目の指示で一番下に置くことになった.
下の計画は, それを反映したもの.

## 計画

### 作るもの

- マッチの画面の一番下 (マッチの削除の欄よりも下) に, 「トップページへ」のリンクを置く.
- ブラウザでも Android アプリの中でも出す. アプリは WebView の戻るでも戻れるが, URL を貼ってマッチを開いたときは, 戻っても前の画面がないことがあるため.
- マッチが見つからないときの画面には, もうリンクがあるので変えない.

### 変えるファイル

| ファイル | 変えること |
|---|---|
| `web/src/client/pages/match-page.ts` | 一番下にリンクを足す |
| `web/src/client/style.css` | リンクの見た目 (上の欄との間) |
| `docs/web/app.md` | マッチの画面にトップページへのリンクがあることを書く |

### テストの観点

- 画面だけの変更で, 規則と API は変えないので, 自動のテストは足さない.
- 画面 (人に依頼する): 参加前, 参加後, リーダーのどの状態でも, リンクからトップページに戻れる. アプリの中でもトップページが WebView の中で開く.

### コミットの分け方

1. `docs: 計画 マッチの画面からトップページに戻るリンクを足す を残す`
2. `feat: マッチの画面にトップページへのリンクを足す` (画面, 見た目, app.md)
